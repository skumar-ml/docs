The [**NSD Briefs program page**](https://www.nsdebatecamp.com/briefs) is a marketing and catalog page for debate briefs. It shows subscription options (annual plans and single brief) and a **VIEW OUR BRIEFS** section where individual briefs are loaded by an embedded script that calls `getBriefDetails`, renders cards, and opens a Preview modal. This page does not handle checkout—users go to [**Briefs Checkout**](https://dashboard.mintlify.com/nsd/briefs-checkout/checkout) to purchase.

## **Technical**

### **Overview**

The page includes an **inline script** that runs on `DOMContentLoaded`. It defines a `Briefs` class that:

1. Calls `getBriefDetails` (no query params) to get the **briefs** array.
2. Renders cards into a fixed container and attaches Preview click handlers.
3. Shows a loading spinner during fetch and (optionally) while the preview PDF loads; shows errors via `alert` or similar if the request fails or returns no briefs.

There is **no separate build step**—the script is embedded in the page (e.g. Webflow embed or inline `<script>`).

### **API — get brief data**

- **Endpoint:** `GET {apiBaseURL}getBriefDetails`.
- **Response:** JSON with a **briefs** array. Each item includes at least `briefId, title, description, topic, price, displayOrder,` and optionally `preview_pdf_url`. Same backend as camp/briefs-checkout: `getBriefDetails.py` (reads `briefs` collection, active, sorted by display_order).
- Only the **briefs** part of the response is used on this page; `briefEvents` and `debateEventId` are not used here.

### **Flow (embed script)**

- **Init:** On DOMContentLoaded, `new Briefs({ apiBaseURL: "…" })` runs. Constructor calls `getBriefs()` and `addCloseModalHandler().`
- `getBriefs()`**:** `showLoading()` (spinner), `fetchData("getBriefDetails"),` then:
  - If `response && response.briefs` and length \> 0: `renderBriefs(response.briefs)`, `attachPreviewHandlers(response.briefs).`
  - Else: `showError(...)` (“No briefs are currently available.” or “Unable to load briefs…”).
  - finally: `hideLoading().`
- **renderBriefs(briefs):** Finds container `.view-briefs-cards-container .view-briefs-inner-flex`, sets `innerHTML = ""`, sorts by `displayOrder`, then for each brief appends `createBriefCard(brief, false).`
- `createBriefCard(brief, isSelected)`**:** Creates a `div.brief-card-info` with `data-brief-id = brief.briefId` and inner HTML: title (`.pdf-briefs-title`), PDF icon, description (**.**`pdf-brief-text-medium`), “Topic: …” (**.**`pdf-brief-text-small`), price (**.**`pdf-brief-price`), and a **Preview** link (**.**`briefs-preview-btn` with `data-brief-id`). Returns the card element (selection state is not used for purchase on this page).
- **attachPreviewHandlers(briefs):** For each `.briefs-preview-btn`, on click: resolve **brief** from **briefs** by `data-brief-id`; if `brief.preview_pdf_url` exists, `showLoading(),` set `modal.style.display = "flex"`, set `iframe.src = brief.preview_pdf_url`, and `hideLoading()` in `iframe.onload`; else set button text to “Not Available” and `hideLoading()` after a short delay. Close button (`.close-preview` or `#close-preview`) sets `modal.style.display = "none"` and `iframe.src = "".`

### **DOM and IDs**

- **Container:** `.view-briefs-cards-container .view-briefs-inner-flex` — target for **renderBriefs** (all cards appended here).
- **Modal:** `#briefs-preview-modal` — overlay for PDF preview; `#preview-frame `— iframe that loads `preview_pdf_url; #close-preview` — close button.
- **Spinner:**` #half-circle-spinner` — shown during `getBriefs` and optionally while the preview PDF loads; script shows/hides it and its parent as needed.

### **Data shape (brief object)**

From `getBriefDetails` (briefs array), each item used in the embed includes:

- **briefId** — string (e.g. MongoDB ObjectId string); used in **data-brief-id** and to find the brief for Preview.
- **title** — display title.
- **description** — short description.
- **topic** — topic label (e.g. “January 2025”).
- **price** — number; displayed as `$X.XX`.
- **displayOrder** — number; used to sort cards.
- **preview_pdf_url** — optional; if present, Preview opens it in the iframe; otherwise the button shows “Not Available.”

### **Differences from briefs-checkout page**

- **Program page (/briefs):** Embed script only uses `response.briefs`; single container; no accordions, no `briefEvents`, no cart, no payment. Purpose: catalog and preview.
- **Briefs checkout (/briefs-checkout):** Uses `briefs-events-checkout.js`; uses both `briefs` and `briefEvents`; accordions (Annual vs Single), Order Details, `createCheckoutUrlForBrief `/ `createCheckoutUrlForBriefEvent`; purpose: purchase flow.

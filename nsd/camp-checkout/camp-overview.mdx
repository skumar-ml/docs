## Summer Camp Overview Page

Most checkout journeys begin from the [camp overview page](https://www.nsdebatecamp.com/summer-camps-overview).

The **Summer Camp Overview page** displays a list of available summer programs.\
All program-level information on this page is **fully driven by Webflow CMS collections**. Each row on the page represents one Webflow collection item (one summer program). The collection item contains structured fields that control what appears on the overview page and what expands when a program row is clicked.

## Information Displayed on the Page (from Webflow CMS)

Each program row is powered by a single Webflow CMS collection item and includes:

- **Program Name**
- **Program Format** (In-Person / Online)
- **Program Duration**
- **Program Price**
- **Program Dates**
- **Program Location**
- **Program Detail Page Link** (Learn More button) 

  Clicking this button directs the user to the detailed program(Eg - [link](https://www.nsdebatecamp.com/lincoln-douglas-flagship)) page.\
  The link is controlled by the **Webflow CMS Program Detail Page** field.
- **Register Link** (Register button → checkout flow)

  Clicking this button directs the user to the registration or checkout flow.\
  The link is controlled by the **Webflow CMS Register Link** field.

## Summer Camps Overview Page

Most checkout journeys begin from the [camp overview page](https://www.nsdebatecamp.com/summer-camps-overview).

The **Summer Camps Overview page** displays a list of available summer programs.\
All camp information on this page is fully driven by **Webflow CMS collections**. Each row represents one Webflow collection item (i.e., one summer program). Each collection item contains structured fields that control what appears on the overview page.

## Information Displayed on the Page (from Webflow CMS)

Each camp row includes: Camp Name, Format (In-Person / Online), Duration, Price, Dates, and Location.

### Program Detail Page Link (Learn More Button)

Clicking the **Learn More** button directs the user to the detailed camp page.

### Register Link (Register Button → Checkout Flow)

Clicking the **Register** button opens registration options:

- Residential
- Commuter

Each option directs the user to a **different checkout page**.

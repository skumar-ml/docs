   **The checkout flow follows a multi-step process:**

   Login / Sign-up → Student Details → Briefs Selection → Payment

   Each step must be completed before proceeding to the next.

   ### Step 1: Login / Sign-up via the cart page

   When a user enters the checkout flow, they must log in or create a **Parent Account** before continuing.

   <Frame>
     ![Image](/images/image-150.png)
   </Frame>
   - **Existing Parent (Login):** Users see _“Already have an account?”_ with a Login button. After successful login, they are moved to the Student Details step.
   - **New Parent (Create Account):** Users complete the Create Account form. Upon successful creation, they are automatically logged in and moved to the Student Details step.

### Saved Student Profiles

- Parents enter or select student information.
- Existing student profiles can be selected from a dropdown, which auto-fills the form.
- Required details include:\
  Student Name, Email, Grade, School, and Gender.
- Clicking **Next** saves the information and triggers a popup offering discounted bundle programs for future sessions.

### Payment Methods

Users select their preferred payment option: ACH / Bank Transfer, Credit / Debit Card, or Buy Now, Pay Later (via Affirm).

### Pay Button

Clicking the **Pay Now** button in the **Order Details** section redirects the user to the secure **Stripe payment page**, where all added programs and briefs are displayed to complete the transaction.

### After Payment

Upon successful payment, the user is redirected to a [confirmation (success) page](https://www.nsdebatecamp.com/payment-confirmation?programId=5&transactionID=cs_live_b1R679Kpw5yC6PbDFDEE1nOxB6KjKhhca54xbIe7TJjdYbcEzSEhoFCLqJ) and the student is officially registered for the class.

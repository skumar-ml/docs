## Signing up or Logging in

Users can create new accounts on our [sign-up page](https://www.nsdebatecamp.com/sign-up); while existing users can log in through the [log-in page](https://www.nsdebatecamp.com/log-in). Each account is uniquely associated with an email address.

Users who have forgotten their password can reset it from the log-in page.

## Account Types

The most important distinction between accounts is the **account type**, which can be **parent, student, or coach**. We support multiple account types to ensure role-based access.

These distinctions determine what each account type can access and do:

- Both **parent** and **student** accounts can register for NSD classes.
- **Parent** and **student** accounts see the same portal.
- Only coach accounts can access the NSD Coach Portal, which we need to work on.

## Technical Details

### Memberstack

Memberstack handles all of the member logic for the NSD site. This includes sign-in auth, password encryption, log-in redirects, gated content, and member-specific pages. NSD uses Memberstack V1; the account can be accessed via https://app.memberstack.io/login. Configuration and member data are separate from BDC.

### Family Architecture

Parent and student accounts are connected through a unique `familyId` that links family members together. This supports multiple students under (at least one) parent account and handles various sign-up scenarios.

The logic is centralized in the account-creation flow and behaves as follows:

**1. Parent-first ownership model**

- The **parent record is the source of truth** for `familyId`.
- When a signup includes a `parentEmail`, the system first looks up an existing parent by that email.

**2. FamilyId generation**

- If no existing parent is found:
  - A new `familyId` is generated (non-guessable, derived from parent email and digits) and assigned at parent account creation.

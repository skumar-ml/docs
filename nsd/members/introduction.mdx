## Signing up or Logging in

Users can create fresh accounts on our [sign-up page](https://www.nsdebatecamp.com/sign-up); users with existing accounts can log-in on our [log-in page](https://www.nsdebatecamp.com/log-in). Accounts are uniquely associated with an email address.

Users that have forgotten their password can do a password reset on the log-in page.

## Account Types

The most important distinction between accounts is the `accountType`, which can be `parent`,  `student`, or `coach`. We support multiple account types to ensure role-based access and family linking:

These distinctions control the following:

- Only `parent` accounts can register for NSD classes. A `student` account will be asked to log out and sign-in to a `parent` account during the checkout process.
  - `student` and `parent` accounts see the same portal.
- Only `coach` accounts can access the NSD Coach Portal, which (upon verification) allows them to access functionality like semester class attendance & trial class attendance and the millions.

There currently does not exist any mechanism for the admin or user to change the `accountType`. If a need arises, please inform the tech team, and we'll do it manually.

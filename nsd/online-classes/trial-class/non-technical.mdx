This section explains how administrators manage **Trial Classes** using the Retool admin dashboard.
Trial classes allow prospective students to attend a session before enrolling in a full program.  
Administrators use the Retool dashboard to create, manage, and monitor these classes and the student registrations associated with them.

---

# Admin Management (Retool)

Administrators manage trial classes through the Retool admin dashboard. From this dashboard, administrators can:

- Create trial classes
- Update or reschedule classes
- Delete classes
- View student registrations
- Track attendance

---

## Creating a Trial Class

Administrators can create a new trial class by entering the following information.

| Field | Description |
|------|-------------|
| Date | Date the trial class will occur |
| Start Time | Time the class begins |
| End Time | Time the class ends |
| Start Grade | Minimum grade allowed |
| End Grade | Maximum grade allowed |
| Number of Spots | Maximum number of students allowed |

## Updating or Rescheduling Trial Classes

Administrators can modify an existing class when changes are needed.

For example:

- Changing the **date**
- Adjusting the **start or end time**
- Updating the **number of available spots**

Rescheduling allows administrators to move a class to a different available **time slot**.

---

## Deleting Trial Classes

Administrators can remove a trial class if it should no longer be offered.

Deleting a class:

- Removes it from the system
- Prevents new student registrations

## Tracking Attendance

After the trial class takes place, administrators can mark whether each student attended the session.

Tracking attendance helps:

- Identify students who completed the trial class
- Follow up with families about enrollment opportunities

# Trial Class Page (Student Registration)

Students register for trial classes through the public Trial Class page.

Parents can:

- View available upcoming trial classes
- Select a class
- Submit student and parent information

Once submitted, the registration becomes visible in the **Retool admin dashboard**, where administrators can review the registration and track attendance.
---

### Student Information
- First name, Last name, Grade

### Parent Information
- First name, Last name, Email address, Phone number

Parents may also optionally include the student's **previous debate experience**.

After submitting the form:

- The student is registered for the selected trial class.
- The registration is saved in the system for administrators to review.

---

# Automated Notifications

After a registration is completed, the system may automatically trigger workflows such as:

- Sending confirmation emails
- Notifying internal teams
- Adding the parent to internal systems

These automations help staff manage registrations and follow up with families.

---

# Summary

The Trial Class system allows administrators to manage trial classes through the Retool dashboard.

Administrators can:

- Create and schedule trial classes
- Update or reschedule classes
- Delete classes
- View student registrations
- Track attendance for each student

Students register through the public Trial Class page, and those registrations appear in the admin dashboard for administrators to review and manage.

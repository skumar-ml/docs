---
title: "Trial Class Management (Retool)"
---

This section explains how administrators manage **Trial Classes** using Retool.  
Admins can create trial classes, manage registrations, and track attendance.

## Overview

Trial Classes allow prospective students to attend a session before enrolling.

Admins can use Retool to:

- Create trial class sessions
- View scheduled trial classes
- Manage student registrations
- Track attendance

---

# Creating a Trial Class

Admins can create a new trial class by entering:

- Date
- Start time
- End time
- Grade range
- Number of available spots

After creation, the trial class becomes available for registration on the Trial Class page.

---

# Viewing Trial Classes

Admins can view upcoming trial classes.

The system automatically:

- Shows **only upcoming classes**
- Sorts classes **by date**

Admins can see:

- Date
- Time
- Grade range
- Available spots

---

# Editing Trial Classes

Admins can update trial class information if changes are needed.

Editable fields include:

- Date
- Start time
- End time
- Grade range
- Number of available spots

---

# Deleting Trial Classes

If a trial class should no longer be offered, admins can delete it.

Deleting a class removes it from the system and prevents new registrations.

---

# Viewing Student Registrations

Admins can view all registrations for a trial class.

Registration details include:

- Student name
- Student grade
- Parent name
- Parent email
- Parent phone
- Attendance status

---

# Tracking Attendance

After the trial class occurs, admins can mark students as **attended**.

This helps track which students participated in the trial class.

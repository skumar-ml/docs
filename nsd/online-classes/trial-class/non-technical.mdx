---
Title: "Trial Class System (Overview)"
---

This section provides a high-level overview of the **Trial Class system**.  
It explains how trial classes are scheduled, how parents register students, and how administrators manage registrations and attendance.

The Trial Class system allows prospective students to attend a class before enrolling in a full program.

---

# Overview

The Trial Class system supports two main user groups:

**Administrators**
- Schedule and manage trial classes
- View student registrations
- Track attendance

**Parents / Students**
- View available trial classes
- Register for a trial class slot

---

# How the System Works

The trial class process has three main steps:

1. **Trial Class Scheduling** – Administrators create trial classes through the admin dashboard.
2. **Trial Class Registration** – Parents select a class and submit a registration form.
3. **Attendance Tracking** – Administrators record whether students attended the class.

---

# Admin Management (Retool)

Administrators manage trial classes through the admin dashboard.

From the dashboard, administrators can:

- Create new trial classes
- Edit or reschedule classes
- Remove classes
- View student registrations
- Track attendance

---

## Creating a Trial Class

When creating a trial class, administrators specify:

| Field | Description |
|------|-------------|
| Date | Date when the class will take place |
| Start Time | When the class begins |
| End Time | When the class ends |
| Start Grade | Minimum grade allowed |
| End Grade | Maximum grade allowed |
| Number of Spots | Maximum number of students allowed |

Once created, the class becomes available on the **Trial Class registration page**.

Only **upcoming classes** are shown to users.

---

## Managing Trial Classes

Administrators can update existing classes if changes are required.

Common updates include:

- Changing the **date**
- Adjusting **start or end times**
- Increasing or decreasing the **number of available spots**

Administrators can also remove a trial class if it should no longer be offered.

---

## Viewing Registrations

Administrators can view all students who registered for a trial class.

Each registration includes:

### Student Information
- First name, Last name, Grade

### Parent Information
- First name, Last name, Email address, Phone number

This information allows administrators to contact families if needed.

---

## Tracking Attendance

After a trial class occurs, administrators can mark whether each student attended.

Tracking attendance helps:

- Identify students who completed the trial class
- Follow up with families about enrollment opportunities

---

# Trial Class Registration (For Parents)

Parents can register their student for a trial class through the **Trial Class page**.

The page displays all available upcoming classes.

Each class shows:

- Date, Time, Grade range, Available spots

Parents simply select a class and complete the registration form.

---

## Registration Form

Parents must provide the following information.

### Student Details
- First name, Last name, Grade

### Parent Contact Information
- First name, Last name, Email address, Phone number

Parents may also optionally include the student’s **previous debate experience**.

After submitting the form, the student is registered for the selected trial class.

---

# Automated Notifications

When a student registers for a trial class, the system can automatically trigger internal workflows such as:

- Sending confirmation emails
- Notifying staff
- Adding contacts to internal systems

These automations help streamline communication and follow-up.

---

# Summary

The Trial Class system provides a simple workflow for both administrators and families.

**Administrators can:**
- Create and manage trial classes
- View student registrations
- Track attendance

**Parents can:**
- View available classes
- Register their student for a trial class

This system helps prospective students experience a class before enrolling in a full program.

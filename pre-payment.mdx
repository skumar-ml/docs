## 1. Login / Signup / Cart Redirection

### Authentication

The user must be logged in (parent account) to access camp checkout. Memberstack detects the active member session on page load. Login/signup sections are shown before authentication; the multi-step checkout is hidden until the user is authenticated.

**Implementation:** **`nsd/checkout_with_abandoned.js`** (class **`CheckOutWebflow`** extends **`BriefsUpsellModal`**). Backend: **`nsd_aws/api/createCheckoutUrlsByProgram.py`**, **`nsd_aws/api/updateStripeCheckoutDb.py`**.

### Cart / Checkout Entry

Checkout is entered from the [camp overview page](/nsd/camp-checkout/camp-overview) or a program detail page (e.g. via the **Register** button). Program context is passed into the checkout flow as **`memberData`**. If the user leaves before paying, **abandoned-cart** recovery can restore state from `localStorage` (`checkOutData`) or a backend lookup by `memberId`; see [Payment](/nsd/camp-checkout/technical/payment) for returning from Stripe and resuming.

## 2. Program Selection

The first checkout tab is **`checkout_program`** (program summary). The user sees the selected camp program; context comes from **`memberData`**, which includes:

- **programId**, **programName**, **programCategoryId**, **slug**
- **programStartDate**, **programEndDate**
- **achAmount**, **cardAmount**, **payLaterAmount**
- **productType**, **site_url**

Clicking **Next** on **`next_page_1`** (handled in **`addEventForPrevNaxt()`**) moves to the student details tab (**`checkout_student_details`**).

## 3. Student Profile & Information Collection

**Form location:** Tab **`checkout_student_details`**. Fields: First Name, Last Name, Email, Grade, School, Gender.

**Validation:** The frontend validates that the student email is unique (e.g. different from parent) via **`checkUniqueStudentEmail()`** (`nsd/checkout_with_abandoned.js`). If validation fails, **`checkout-form-error`** is shown and the user cannot proceed to payment.

When the user clicks **Next** on the student details tab (**`next_page_2`**), inside **`addEventForPrevNaxt()`**:

1. **`storeBasicData()`** saves form data to `localStorage` for pre-fill and abandoned-cart recovery (see **`checkout_with_abandoned.js`**).
2. **`initializeStripePayment()`** is called — POST to **`.../camp/createCheckoutUrlsByProgram`** (see [Payment](/nsd/camp-checkout/technical/payment)); returns **achUrl**, **cardUrl**, **payLaterUrl**.
3. After the promise resolves, **`updateStudentDetails(checkoutData)`** is called with **`[$this.$checkoutData.achUrl, $this.$checkoutData.cardUrl, $this.$checkoutData.payLaterUrl]`** — POST to **`.../camp/updateStripeCheckoutDb`** (**`nsd_aws/api/updateStripeCheckoutDb.py`**).
4. **`updateOldStudentList()`** refreshes the saved-student list.

**API (create URLs):** **`POST .../camp/createCheckoutUrlsByProgram`** — **`nsd_aws/api/createCheckoutUrlsByProgram.py`** **`lambda_handler`**. Request body (from **`initializeStripePayment()`**): **email**, **label**, **programId**, **successUrl**, **cancelUrl**, **memberId**, **programCategoryId**, **supplementaryProgramIds**, **productType**, **programStartDate**, **programEndDate**, **achAmount**, **cardAmount**, **payLaterAmount**, **briefEventIds** (optional), **device**, **deviceUserAgent**, **source** (e.g. **`"cart_page"`**). Backend uses **`getCustomerId(email)`** and **`createCheckoutSessionUrl(...)`**; inserts into **`stripe_checkout_customer`**; returns **cardUrl**, **achUrl**, **payLaterUrl**, **checkoutId**, **success: true**.

## 4. Optional Supplementary Programs & Briefs

### Supplementary Programs

Selected supplementary (add-on) programs are stored in the hidden field **`suppProIds`** (element ID **`suppProIds`** in **`checkout_with_abandoned.js`**; value is a JSON array of program IDs). They are sent in **`createCheckoutUrlsByProgram`** as **`supplementaryProgramIds`** (parsed from **`JSON.parse(suppProIdE.value)`** in **`initializeStripePayment()`**). The checkout UI shows supplementary options in **`checkout-supplimentary-data-2`** and **`checkout-supplimentary-data-desktop`**; selection is tracked and included when creating checkout URLs.

### Briefs Upsell (Admin Only)

If **`memberData.isAdmin`** is true, the **BriefsUpsellModal** (from **`BriefsUpsellModal`** in `checkout_with_abandoned.js`) can be shown after the user reaches the payment step. Selected brief events are sent as **`briefEventIds`** in the same **`createCheckoutUrlsByProgram`** request. See [Upsells](/nsd/camp-checkout/upsells) for product-level details.
